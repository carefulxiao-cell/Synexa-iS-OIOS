## 一、体系品牌架构全局说明（请 iS-Core 更新至 GitHub 仓库及超智官网）

### 1.1 品牌架构总览

**超智（Synexa）= 母品牌 + 中央引擎·中台**

超智是整个体系的母品牌与中央协同汇聚层。对内，超智负责四大业务引擎·中台之间的数据互通、资源调度与协同逻辑；对外，超智是所有产品线的品牌背书来源。超智的价值不在于直接提供业务服务，而在于让四个独立引擎产生「1+1+1+1 > 4」的协同效能。

**超级系列（Super Series）= 超智旗下对外产品线品牌**

「超级」是超智旗下面向有价值行业（餐饮/医疗/养老/供应链等）提供的 **High Quality & Stability 智能工具集合体**的产品线品牌。每个超级产品对应一个主题领域，服务特定行业的运营效能提升需求。超级系列是超智从内部协同体系走向对外商业化的核心载体。

### 1.2 四大引擎·中台与超级系列对应关系

四大业务引擎·中台各自完整自洽，可独立运转，同时通过超智中央层实现跨引擎协同：

| 引擎·中台（内部定位） | 超级系列产品（对外品牌） | 主题定位 | 典型服务对象 |
|---------------------|----------------------|---------|------------|
| **NexFlow** | 超级项目管理 | 一站项管协同中台 | 各行业复杂项目团队、工程管理、开业筹备 |
| **Nex2U** | 超级健康管理 | 健康稳态服务中台 | 医疗机构、养老院、健康管理机构、个人 |
| **Nexsply** | 超级供应链管理 | 供应链管理中台 | 餐饮企业、制造业、零售供应链 |
| **NexChef** | 超级餐食服务 | 健康餐食服务中台 | 餐饮企业、医院食堂、养老院、团餐运营商 |

**行业组合示例**：
- 给宜源华（食堂运营商）提供的工具方案 = 超级项目管理 + 超级餐食服务 + 超级供应链管理
- 给医院提供的工具方案 = 超级项目管理 + 超级健康管理 + 超级餐食服务
- 给养老院提供的工具方案 = 超级健康管理 + 超级餐食服务 + 超级项目管理

超智负责把这些模块协同起来，对外输出完整的行业解决方案，而不是让客户自己拼装。

## 二、iS-NexFlow 定位申请

### 2.1 基本信息

| 字段 | 内容 |
|------|------|
| 系统名称 | **NexFlow · 一站式项目协同智能平台** |
| 品牌标识 | NexFlow · IntP·Lab |
| 超级系列对应 | 超级项目管理 |
| 体系代号 | iS-NexFlow |
| 职能类型 | PCS（项目协同系统） |
| 层级申请 | G·集团级（与 Nex2U / Nexsply / NexChef 同级） |
| 主题定位 | 超级项目管理 / 一站项管协同中台 |
| 当前版本 | V2.6（实战测试中） |
| 部署地址 | pyzxyy.sitechnology.com.cn |

### 2.2 定位核心句

> **NexFlow — 让项目里的每一条信息都有去处、有状态、有记录、可交付。**

NexFlow 是面向复杂项目全生命周期的一站式协同智能平台。它不是任务清单工具，也不是项目管理软件，而是一个**将项目中所有信息流（任务、人员、文件、问题、资料、运营、人力）统一纳管的协同中台**，以「信息不出系统」为核心设计原则，以「AI 辅助录入与分析」为效能放大器，以「模块化可扩展」为商业化基础。

## 三、八大核心模块（完整定义）

### 模块一：任务管理（Task Management）
**状态**：已上线（V2.0~V2.6 持续迭代）

**核心能力**：
- 全局任务视图：多维筛选（阶段/分类/状态/风险/优先级）、关键路径标记、拖拽排序
- 任务详情：inline 编辑、关键重点字段、备注/沟通记录（关联用户）、进度追踪
- AI 录入：自然语言/截图/文档三通道输入，三阶段状态机（解析→精修→提交）
- 任务编号体系：`AD.01 / BA.02 / FN.03` 等分类编号，全局唯一可追溯
- 优先级算法：P 值自动计算（紧迫度 × 重要度 × 风险系数）

**边界说明**：任务管理是 NexFlow 的核心模块，其他所有模块均可与任务建立关联。

---

### 模块二：人员协同（Team Collaboration）
**状态**：已上线（V2.0~V2.6）

**核心能力**：
- 人员任务视图：按成员查看任务分布与执行状态，支持超期/今日到期/本周到期分组
- 任务点击进入详情编辑
- 成员分组：协调组 / 运营组 / 行政组 / 信息组 / 其它
- 权限体系：管理员 / 项目组员，可见范围 A/O/C/P 四级
- 注册审批流：新用户强制审批，未审批用户无法访问系统

**边界说明**：本模块聚焦「任务视角的人员协同」，不含人力资源管理（见模块七）。

---

### 模块三：进度与看板（Progress & Kanban）
**状态**：已上线（V2.0~V2.3）

**核心能力**：
- 甘特图式进度图：阶段时间轴、任务分布可视化
- 状态看板：按状态列分组，支持拖拽流转
- 风险预警：高风险任务自动标记，风险预警页集中展示

**边界说明**：可视化呈现层，数据来源于任务管理模块。

---

### 模块四：资料清单（Document Checklist）
**状态**：已上线（V2.6）

**核心能力**：
- 结构化资料条目管理：序号/类别/资料名称/资料版本/提交状态/备注
- 预置行业标准清单（当前：番禺中心医院进场 22 条标准清单）
- 条目状态追踪：待提交 / 已提交 / 审核中 / 已通过 / 退回修改
- 文件附件（V2.7 规划中）：条目级文件上传，S3 存储，版本历史

**边界说明**：聚焦「需要提交给外部方的资料」的追踪管理，不是内部文件库。

---

### 模块五：问题清单（Issue Tracker）
**状态**：已上线（V2.6）

**核心能力**：
- 问题录入：来源（内部/院方/合作方/其他）、优先级、类别、详细描述
- 问题编号：`IS.001` 格式，全局唯一
- 状态流转：待处理 → 处理中 → 待确认 → 已解决 → 已关闭
- 统计看板：各状态数量汇总
- 文件导入拆分（V2.7 规划中）：一份文件导入后可拆分为独立问题条目，支持勾选汇总导出

**边界说明**：聚焦「项目执行过程中出现的问题」的追踪，不是客诉系统。

---

### 模块六：中央资料仓（Central Document Repository）
**状态**：规划中（V2.7~V3.x）

**核心能力规划**：
- 条目级文件附件（V2.7）：任务/问题/资料条目均可挂载文件，S3 存储
- 文件版本管理（V3.0）：每次上传自动记录版本，可回溯历史版本，变更通知
- 跨模块关联（V3.0）：通用 `relations` 表，任务↔资料↔问题双向关联，导出时呈现关联字段
- 一键交付包（V3.x）：按项目/类别/状态筛选，一键导出当前最新版本的所有资料，生成交付包

**边界说明**：「信息不出系统」的核心基础设施，是 NexFlow 区别于普通项目管理工具的关键差异。

---

### 模块七：人力管理（HR Management · 稳定信息层）
**状态**：规划中（V3.0）

**核心能力规划（仅稳定信息层）**：
- 花名册：员工姓名、岗位、分组、联系方式、入职日期
- 证件管理：健康证/上岗证/培训证等证件有效期记录与到期预警
- 访谈评估：入职前访谈记录、评估结论、录用建议
- 培训完成状态：培训项目与完成情况记录
- 排班原则：记录核心排班原则（如「早/中/晚三班制，最少休息间隔 12 小时，每周至少休息 1 天」），文字记录，不做自动排班计算

**边界说明**：NexFlow 只保留稳定信息层，动态排班管理（班次详情/调班/考勤）归属**人力管理主题专项 iS-PCS**，不在 NexFlow 实现，通过接口互通。

---

### 模块八：日常运营（Daily Operations）
**状态**：规划中（V3.0）

**核心能力规划**：
- 菜单管理：三周菜单提交、审核、版本管理（与 NexChef 互通接口）
- 供应商管理：供应商台账、资质文件、合作状态（与 Nexsply 互通接口）
- 设备台账：设备清单、维保记录、使用责任人
- 日报/周报：运营数据录入、自动汇总、导出报告
- 检查记录：食品安全检查、卫生检查、整改追踪
- 成本管理：食材成本、运营成本、月度汇总

**边界说明**：聚焦「项目日常运营的标准化管理」，与 NexChef / Nexsply 通过接口互通，不重复建设。

## 四、跨引擎协同接口规划（V3.x）

NexFlow 作为「一站项管协同中台」，是四大引擎在项目执行层面的汇聚点：

| 数据流向 | 触发条件 | 协同效果 |
|---------|---------|---------|
| Nexsply → NexFlow | 采购订单状态变更 | 自动更新 NexFlow 对应任务的进度和资料状态 |
| NexFlow → Nexsply | 任务「采购」类型创建 | 自动在 Nexsply 生成采购需求单 |
| NexChef → NexFlow | 菜单方案确认 | 自动写入 NexFlow 运营模块的菜单记录 |
| Nex2U → NexFlow | 健康评估结论 | 关联至对应人员的人力管理档案 |
| NexFlow → 全部 | 项目里程碑达成 | 触发各引擎的下一阶段任务启动 |
