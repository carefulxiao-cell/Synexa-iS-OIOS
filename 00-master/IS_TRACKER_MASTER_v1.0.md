## 字段说明

| 字段 | 说明 |
|---|---|
| **#** | 全局序号，不随优先级变动 |
| **优先级** | P0~P4 (P0=紧急阻塞 / P1=立即推进 / P2=基础设施 / P3=孵化 / P4=排队) |
| **项目/引擎** | 归属名称 |
| **类型** | iS模块 / 引擎 / 基础设施 / 体系任务 |
| **当前状态** | Step X 或阶段描述 |
| **下一步行动** | 可执行动词短语 |
| **阻塞/依赖** | 前置条件 |
| **执行工作空间** | 去哪个对话组推进 |
| **最后更新** | YYYY-MM-DD |
