# TRIGGER_CHEATSHEET_SKILL · 触发词速查技能

> **版本**：v1.0
> **创建日期**：2026-05-03

> **定位**：Synexa iS 体系全局触发词速查表，供用户在任意工作空间随时调出。

---

## 一、技能定义

本 Skill 旨在解决「触发词遗忘」问题。通过在全局自定义指令中注入单一触发词（如 `触发词速查`），AI 将读取本文件，并向用户输出结构化的全局触发词清单。

---

## 二、触发词与动作映射

| 触发词 | 动作说明 | 预期输出/结果 |
|---|---|---|
| `触发词速查` | 读取本文件，输出全局触发词汇总表 | 结构化 Markdown 表格 |
| `触发词速查 [模块名]` | 读取本文件，仅输出指定模块的触发词 | 过滤后的 Markdown 表格 |

## 四、接入声明模板

为使本 Skill 生效，需在全局自定义指令（或各工作空间规范）中加入以下声明：

```markdown
【Skill 接入声明】
本工作空间已接入以下 Skill：
- 触发词速查 Skill：`触发词速查` / `触发词速查 [模块名]`（定义文件：`00-master/TRIGGER_CHEATSHEET_SKILL_v1.0.md`）
```
