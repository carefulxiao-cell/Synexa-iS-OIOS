## 台定位

- **覆盖范围**：番医饭堂全部物理岗位的岗责定义、主能副能、机动支援范围、职业通能、专项培训、数智配给矩阵、职能域覆盖分析、人员能力档案、人力缺口与异常管理。
- **不覆盖**：排班执行细节归属运营推进台；薪酬结构与具体数字归属财务管控台；招聘流程归属超智中台；任务全生命周期管理归属任务跟踪台。
- **与其他台的关系**：
  - 与任务跟踪台共享：每日必交付物、异常事项、待处理事项。
  - 与运营推进台共享：排班执行、日常 SOP、异常响应路径。
  - 与财务管控台共享：人力成本、薪酬口径、绩效数据接口。
  - 与项目总基线共享：共同内核、高价值参照对象、可迁移精华。
- **本台定位**：不是普通岗位表，也不是排班表，而是围绕"谁负责、谁协同、谁支援、谁复核、谁沉淀"建立的人力协同控制台。

## CH04｜架构定位、协同链条与原则

### CH04.1｜精简协同链条

```
L0 项目负责人 / 最终裁决人
   ↓ 方向、边界、关键裁决
L1 中台协同层
   ↓ 审查、协调、异常判断、培训推进
L2 数智支持层
   ↓ 提醒、记录、整理、分析、生成报告
L3 前线执行层
   ↓ 录入、上报、执行、反馈、服务交付
```

### CH04.2｜协同原则

| 原则 | 说明 |
|---|---|
| 指挥链短 | 日常协同尽量不超过两层，避免层层转述。 |
| 人负责任 | 数智工具可以提醒、整理、分析，但不替代岗位责任。 |
| 前线简单 | 前线动作要清楚、轻量，不让工具变成负担。 |
| 中台复核 | 中台负责判断、复核、异常协调和培训推进。 |
| 情报先行 | 重要动作前必须有数据、记录或现场信息支撑。 |
| 经验沉淀 | 异常、判断、有效做法必须进入档案或复盘记录。 |

## CH07｜机动支援与补位规则

### CH07.1｜总原则

| 原则 | 说明 |
|---|---|
| 本岗为主 | 每个人首先做好自己的主岗位工作。 |
| 相近可补 | 工作内容相近、风险较低的岗位，可培训后临时支援。 |
| 专业不乱替 | 食安、财务、专项餐、打单、院方沟通等不得随意替代。 |
| 先培训再补位 | 不是缺人就顶上，必须先培训、陪跑、确认。 |
| 结果有人负责 | 临时支援不等于最终负责，关键结果必须由负责人确认。 |

### CH07.2｜典型边界

| 岗位 | 可支援 | 不可随意替代 |
|---|---|---|
| 食堂经理·出品 | 堂食现场协调、配送高峰协调 | 客服打单、财务对账、专项餐营养判断 |
| 客服打单岗 | 订单核对、专线对账辅助 | 厨房出品调度、食安裁决、菜单调整 |
| 仓管员 | 采购验收、库存盘点、缺货上报 | 院方沟通、财务裁决、厨房生产管理 |
| 食安主管 | 留样、消毒、温控、食安提醒 | 菜单研发、收银对账、客户承诺 |
| 厨师长·专项 | 专项餐生产、厨房工艺调整 | 客服打单、配送签收、财务台账 |

## CH08｜职业通能与专项培训

### CH08.1｜职业通能总句

> 任务有闭环，形象有标准，底线有天条，工具能上手，协作能接住，发现多一步。

### CH08.2｜六项能力

| 能力 | 标准 | 要求 |
|---|---|---|
| 任务能力 | 任务有闭环 | 有抓取、有提炼、有确认、有回应、有进度、有结果、有交代、有沉淀 |
| 形象能力 | 形象有标准 | 干净、得体、精神、稳定 |
| 底线能力 | 底线有天条 | 慎独自律、真诚可靠、不泄密、不作假、不贪腐、不传播敏感信息 |
| 工具能力 | 工具能上手 | 会录入、会查询、会提交、会整理、会输出、会复核 |
| 协作能力 | 协作能接住 | 积极听、听得懂、接得住、说得清、交得出 |

## CH09｜人员能力档案

### CH09.1｜能力档案目的

人员能力档案用于记录员工当前岗位状态、主能副能、职业通能、专项培训、数智工具熟练度、可支援事项、不可替代事项、风险提醒和后续培养方向。

### CH09.2｜能力档案字段

| 字段 | 说明 |
|---|---|
| 员工姓名 | 当前人员姓名 |
| 当前岗位 | 当前正式岗位 |
| 岗位类别 | 中台 / 前线 / 专项 / 支援 |
| 主能状态 | 对主能的掌握程度 |
| 副能状态 | 对副能的掌握程度 |
| 职业通能状态 | 六项能力综合状态 |
| 专项培训状态 | 食安、财务、专项餐、打单等专项培训情况 |
| 数智工具熟练度 | 对相关工具的使用能力 |
| 可支援事项 | 已确认可临时支援的事项 |
| 不可替代事项 | 未经授权不得替代的事项 |
| 风险提醒 | 当前观察到的风险 |
| 培训建议 | 后续应补充的培训 |

### CH09.3｜数智工具熟练度

| 等级 | 含义 |
|---|---|
| D0 | 未接入，不会使用 |
| D1 | 可在指导下录入 |
| D2 | 可独立完成日常录入与查询 |
| D3 | 可主动使用工具发现问题、提交改进建议 |
