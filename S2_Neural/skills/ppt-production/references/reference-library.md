# PPT排版参考图库

## 职责与使用方式

图库保存可追溯的结构参考，不直接成为固定模板或品牌系统。先按内容关系检索，再查看对应原图；只在信息量、关系和品牌要求均能适配时采用。不因为“好看”就移植原数据、照片、语言或成果。

每批新图先去重、区分微缩总览与清晰单／双页；保留原图，不覆盖旧编号。下表L编号是稳定图库标识，R／N是本案例别名；项目页M编号不属于图库。双页使用A／B定位，单页无需子标记。

## 以后每项应补充的字段

保存：稳定编号、原图／来源、单页或双页、可见指纹、结构标签、阅读顺序、适用关系、容量判断、不适用情形、验证状态、关联成功或失败案例。

“信息容量”由标题长度、解释行数、模块数量、观看方式与实际渲染共同判断，不将原图四栏当作所有内容都最多四项。项目别名可保留，但不能替代稳定编号。

## 新批次入库流程

接收与核对 → 去重与粒度识别 → 编号与结构描述 → 内容关系匹配 → 在实际页面验证 → 记录评价。

只有用户授权入库时才实施新增；仅讨论参考时不顺便扩建。独立研究与判断达到官方workflow-composer适用条件时按其执行；既有分析的索引转换不重做研究。

原图参考、品牌配置和项目案例分层保存。实际页面验证通过仅更新技术状态；用户未评价的布局不记为已认可。更新图库不改变旧项目的事实或已确认页面。
