# iS-Matrix 能力原子框架概述 (v2.0)

> **版本**：v2.0
> **状态**：Active
> **更新日期**：2026-05-11
> **维护者**：iS-Core (智核中枢)

## 1. 框架定位与第一性原理

iS-Matrix 能力原子框架是 Synexa iS 体系的**核心能力字典与架构蓝图**。
其第一性原理是：**将「内部治理机制」与「对外交付能力」解耦，形成正交双轴架构。**

- **对外（商业交付）**：展示通用认知能力与封装引擎，回答“AI 能帮人类完成什么工作”。
- **对内（系统治理）**：强制执行约束边界与上下文机制，回答“多个 Agent 如何在一个体系内稳定协同”。

## 2. 四层架构解析

本框架采用「约束前置 + 通用能力 + 治理机制 + 封装引擎」的四层结构。

### 第 0 层：约束层（Constraints）
**定位**：所有能力的运行边界，对外不展示，对内强制执行。
- **Con-1**：价值底线与行为原则 (`CORE_PRINCIPLES.md`)
- **Con-2**：角色权限与责任边界 (`RACI.md`)
- **Con-3**：人机交互规范 (`DIALOGUE_FRAMEWORK.md`)
- **Con-4**：工具调用边界 (`TOOL_PRINCIPLES.md`)
- **Con-5**：领域概念边界定义 (`DOMAIN_REGISTRY.md`)

### 第 1 层：通用认知能力层（Universal Cognitive Capabilities）
**定位**：对外交付的语言，引擎组合的原子。基于 DIKW + Bloom + LLM Agent 四模块构建。
- **U1 · 感知与清洗**：多源输入提取 / 非结构化标准化 / 格式识别 / 领域映射
- **U2 · 记忆与检索**：知识库构建 / 语义检索 / 历史上下文关联 / 状态召回
- **U3 · 分析与推理**：逻辑拆解 / 多维对比 / 根因分析 / 数据可视化
- **U4 · 生成与执行**：报告撰写 / 代码生成 / SOP 自动化执行 / API 调用
- **U5 · 决策与判断**：方案评估 / 优先级裁决 / 期望值推演 / 凯利分配

### 第 2 层：体系治理层（System Governance）
**定位**：支撑第 1 层能力稳定可控输出的底层机制，iS 体系核心壁垒。
- **G1 · 上下文管理**：Agent 执行前的状态定位机制（如 `CONTEXT_OS.md`, `_INDEX.md`）
- **G2 · 协同与调度**：任务分发、跨组接力、触发词调用（如 `TRIGGER_CHEATSHEET_SKILL`）
- **G3 · 质量与审查**：版本控制、反向验证、文件治理（如 `VERSION_REGISTRY.md`）

### 第 3 层：封装交付层（Packaged Engines）
**定位**：第 1 层能力 × 第 2 层机制 → 按业务场景组合封装 → 对外交付最小单位。
- **E1**：Skill 封装机制（能力模块化注册与调用）
- **E2**：NexFlow（超级项管引擎）
- **E3**：Nex₂U（智食引擎）
- **E4**：NexChef（餐食方案引擎）
- **E5**：NexLens（数据整理引擎）
- *(待建)*：NexMPC（人力协同）、NexFA（财务管理）、NexTask（任务管理）

## 3. 方法论溯源

本框架的设计融合了全球 9 大主流方法论：
1. **Anthropic Constitutional AI**（第 0 层约束前置）
2. **OECD 核心能力框架**（第 0 层 / 第 1 层交付集群）
3. **DIKW 金字塔 (Ackoff)**（第 1 层认知深度递进）
4. **Bloom 认知分类法 (修订版)**（第 1 层能力分级）
5. **LLM Agent 四模块架构**（第 1 层感知/记忆/规划/行动）
6. **McKinsey 问题解决框架**（第 1 层分析与决策）
7. **MIT 功能分解法**（第 2 层机制拆解）
8. **Microsoft Semantic Kernel**（第 2 层触发词 / 第 3 层 Skill 封装）
9. **TOGAF 业务能力框架**（第 2 层 / 第 3 层架构设计）
