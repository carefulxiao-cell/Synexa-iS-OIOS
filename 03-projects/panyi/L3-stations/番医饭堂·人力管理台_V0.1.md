## CH01｜架构定位 Architecture Layer

### Synexa iS 六层映射

| iS 层级 | 番医对应 | 核心职责 |
|---|---|---|
| L0 人智定向层 | 你 | 战略方向、边界设定、成功标准、最终裁决 |
| L1 场景感知层 | 前线现场信号（iS-Proxima 近场接入） | 实时录入、问题上报、现场执行 |
| L2 协同智能核心 | 数智员工团队（Proxima→Vena→Cortex 串行） | 数据清洗、推演、生成文档 |
| L3 引擎执行层 | Nex·EC 激活子集（9个引擎） | 具体业务引擎执行 |
| L4 人智决策层 | 中台管理岗（运营经理 + 客服经理） | 审查、裁决、协调、异常处理 |
| L5 输出与进化层 | 台账/日志/报告自动生成 + 经验资产沉淀 | 知识沉淀、复盘、Project-to-Skill |

### 番医专项精简4层指挥链

```
L0  你（人智定向）
     ↓ 战略裁决 / 边界设定
L1  中台协同层（运营经理 + 客服经理）
     ↓ 审查 / 协调 / 异常裁决
L2  数智引擎层（Nex·EC 激活9个引擎）
     ↓ 推演 / 生成 / 分析
L3  前线感知层（iS-Proxima 近场接入，前线10个岗位）
     ↓ 录入 / 上报 / 执行
```

> **设计原则**：指挥链≤2层（日常运营：你→中台→前线）；数智员工由你主导，各单元配合；工具放大个体效能，1人干3人的事。
