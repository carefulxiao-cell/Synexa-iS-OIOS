## 4. 提交规范要求 (SOP-003 联动)

执行框在完成本指令包开发并提交 PR 时，必须：
1.  **无原生 SQL 声明**：确认所有数据库操作均通过 Drizzle ORM 完成。
2.  **唯一迁移路径声明**：确认所有表结构变更均已生成迁移脚本（`drizzle-kit generate`）并可成功执行（`drizzle-kit push`）。
3.  **PDC 自检清单**：在 PR 描述中附带已勾选的 PDC 验收标准矩阵。
4.  **生产环境验证**：提供关键功能的本地或测试环境运行截图。
