## 核心原则

> 低面积、点缀式、打印友好；主体白底、细灰线、深灰字，CI 色仅用于识别、状态、图表与关键提示。

**三条强制约束：**

1. **CI 色不做背景大面积铺色**——CI 色只用于点缀、状态标识、图表数据系列、关键提示框的左边框或图标，不得用于页面/卡片/表格的大面积背景填充。
2. **正文与标题只用中性色**——所有正文、标题、说明文字必须使用中性色系（近黑/深灰），不得使用 CI 色作为文字颜色，除非是极小面积的标签文字。
3. **打印友好优先**——所有 CI 色在灰度打印下必须可区分，避免使用饱和度相近的颜色组合。

## CI 色系（8 色）

| 色名 | Hex | 使用场景 | 禁止用法 |
|------|-----|----------|----------|
| **青碧绿**（主强调） | `#28CC83` | 主强调色、正向增长指标、主流程识别、CTA 按钮 | 不得用于错误/警告状态 |
| **青苏**（浅底） | `#A6DD7D` | 低饱和浅底色、健康/通过状态的背景填充 | 不得用于文字颜色 |
| **翠青**（轻强调） | `#BBDE7A` | 轻强调、通过状态、食材/菜品类辅助标识 | 不得与青苏同时大面积使用 |
| **暗梓**（系统级） | `#8B5ACA` | 系统级模块、数据引擎、技术模块识别、iS 体系模块标识 | 不得用于正向/负向业务状态 |
| **亚梓**（低频点缀） | `#E280D2` | 专项标签、非财务主色，仅低频点缀 | 不得用于主流程识别，每页出现不超过 1 处 |
| **淡芯香红**（柔和提示） | `#FF72A1` | 客户体验指标、异常提醒的柔和提示 | 不得用于严重错误（严重错误保留给系统红） |
| **淡叶黄**（预警） | `#DBC35A` | 预警状态、待核查项、价格版本提示 | 不得用于正向状态 |
| **风岩黄**（运营动作） | `#FFB97B` | 运营动作标识、产能安排、排班提示 | 不得与淡叶黄同时出现在同一视图 |

## 全局应用规则

### 文档与报告（PDF / Word）

| 元素 | 规则 |
|------|------|
| 页面背景 | 纸白 `#FFFFFF` |
| 正文 | 近黑正文 `#1F2933` |
| 章节标题 | 深灰标题 `#374151`，加粗 |
| 分割线 | 细线灰 `#D9DEE7`，1px |
| 表头背景 | 深灰标题 `#374151`，文字白色 |
| 交替行底色 | 浅灰底 `#F7F9FC` |
| 高亮框左边框 | 暗梓 `#8B5ACA`（系统/技术内容）或青碧绿 `#28CC83`（正向内容）|
| 高亮框背景 | 对应 CI 色的 10% 透明度近似值 |
| 章节编号 / 标签 | 暗梓 `#8B5ACA`，小号加粗 |

### 系统界面（Web / App）

| 元素 | 规则 |
|------|------|
| 主背景 | 纸白 `#FFFFFF` |
| 侧边栏背景 | 浅灰底 `#F7F9FC` |
| 主 CTA 按钮 | 青碧绿 `#28CC83`，文字白色 |
| 成功/通过状态 | 青苏 `#A6DD7D`（浅底）+ 青碧绿 `#28CC83`（图标/文字）|
| 预警状态 | 淡叶黄 `#DBC35A`（浅底）+ 深灰（文字）|
| 异常/提示状态 | 淡芯香红 `#FF72A1`（浅底）+ 近黑（文字）|
| 系统/技术模块标识 | 暗梓 `#8B5ACA` |
| 运营动作标识 | 风岩黄 `#FFB97B` |
| 数据图表主系列 | 青碧绿 `#28CC83` → 翠青 `#BBDE7A` → 暗梓 `#8B5ACA` → 风岩黄 `#FFB97B`（按优先级顺序使用）|

### 数据图表

| 图表类型 | 主色 | 辅色 | 说明 |
|----------|------|------|------|
| 折线图（正向趋势） | 青碧绿 `#28CC83` | 翠青 `#BBDE7A` | 增长线用主强调色 |
| 柱状图（多系列） | 青碧绿 → 暗梓 → 风岩黄 → 淡叶黄 | — | 按顺序分配，不跳色 |
| 状态分布饼图 | 青碧绿（正常）/ 淡叶黄（预警）/ 淡芯香红（异常）| — | 三色固定语义 |
| 热力图 | 青苏 `#A6DD7D`（低）→ 青碧绿 `#28CC83`（高）| — | 单色渐变 |

### 打印规则

- 所有 CI 色在黑白打印时必须通过灰度对比测试（灰度值差异 ≥ 30）
- 打印版本中，高亮框背景色降低至 5% 透明度或去除，仅保留左边框
- 表头背景在打印版本中保留深灰 `#374151`，确保可读性
