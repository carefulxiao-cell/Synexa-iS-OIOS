# QUICK_BRIEF_SKILL · 快速概述技能

> **版本**：v1.0
> **状态**：Active
> **更新日期**：2026-05-11
> **维护者**：iS-Core（智核中枢）

---

## 1. 定位

这是一个**通用信息提炼与标准化输出技能**。

适用于任何对话、项目、系统或主题。触发后，按统一模板将当前上下文中的核心信息提炼为结构化概述卡片，用于**对齐、交付、传递、表达**。

---

## 2. 触发词

```
快速概述
快速概述 [指定对象]
```

- 不指定对象时：默认对**当前对话/任务**进行概述。
- 指定对象时：对该对象（项目/引擎/框架/决策/方案）进行概述。

---

## 3. 输出模板（标准概述卡片）

收到触发词后，严格按以下结构输出，不增减字段，不自由发挥：

```
【快速概述】[对象名称]
─────────────────────────────────
▌ 一句话定义
[用一句话说清楚这是什么，解决什么问题，服务谁]

▌ 当前状态
[阶段 / 版本 / 进展 / 阻塞项（如有）]

▌ 核心结构
[2-5 条，每条一行，格式：编号 · 名称：说明]

▌ 关键决策 / 共识
[本次对话/任务中已确认的判断或结论，逐条列出]

▌ 待推进事项
[下一步动作，明确责任方和优先级]

▌ 关联文件
[涉及的核心文件或工作空间，附路径或链接]
─────────────────────────────────
```

---

## 4. 执行规则

1. **信息来源**：优先从当前对话上下文提取，不足时读取关联的 GitHub 文件或 CONTEXT_OS.md。
2. **字数约束**：每个字段不超过 3 行，总卡片不超过 30 行。精炼优先于完整。
3. **状态标注**：使用统一符号：✅ 已完成 / ⚠️ 进行中 / ❌ 阻塞 / ⚪ 待启动。
4. **不确定项**：若某字段信息不足，标注「待补充」，不得臆造。
5. **输出语言**：与当前对话语言一致，默认简体中文。

---

## 5. 适用场景示例

| 场景 | 触发示例 | 输出用途 |
|---|---|---|
| 会议结束前 | `快速概述` | 对齐共识，形成会议纪要 |
| 向新成员交接 | `快速概述 NexFlow` | 快速传递项目现状 |
| 跨平台同步 | `快速概述 iS-Matrix 框架` | 生成可粘贴至飞书/GPT 的摘要 |
| 决策前确认 | `快速概述 当前方案` | 确认关键信息无误后再执行 |
| 阶段性复盘 | `快速概述 本阶段进展` | 生成阶段总结卡片 |

---

## 6. 与其他 Skill 的关系

- 本 Skill 是**输出型**技能，不触发任何写入或推送动作。
- 如需将概述结果回写至 GitHub，需额外触发 `状态回写` 或 `更新任务表`。
- 本 Skill 可在任意工作空间（iS-Core / NexFlow / Nex₂U 等）中独立使用，无需前置读取特定文件。
