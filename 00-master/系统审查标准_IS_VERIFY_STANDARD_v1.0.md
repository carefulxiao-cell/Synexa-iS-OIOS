# 系统审查标准 (IS_VERIFY_STANDARD)

**版本**: v1.0
**适用范围**: Synexa iS 体系下所有项目通用
**定位**: 规范系统审查的维度、深度与输出格式，确保审查质量的一致性。本标准为动态演进文件，随项目经验积累持续迭代。

---

## 1. 审查触发条件

审查动作必须在接收到完整的「系统交付包」后方可触发。交付包必须包含以下五大项：
1. 系统交付包文档（功能清单/接口/部署/已知问题）
2. 完整代码包（前端/后端/数据库 Schema/配置）
3. 测试记录（已测/未测/异常/边界场景）
4. 当前变更记录（进行中修改/半完成模块/不稳定模块）
5. 数据一致性说明（同步机制/双轨数据/持久化边界）

## 2. 审查六大维度

审查必须严格覆盖以下六个维度，不得遗漏。

### 2.1 架构风险 (Architecture Risks)
- **模块划分**：职责是否清晰，是否存在“上帝类”或“万能模块”。
- **单点故障**：是否存在某个模块或服务宕机导致整体系统崩溃的风险。
- **耦合度**：模块间依赖是否过重，修改一处是否容易引发多处连锁反应。
- **容错与降级**：在外部依赖失效或高并发时，系统是否具备基本的降级能力。

### 2.2 数据风险 (Data Risks)
- **表结构设计**：是否存在不合理的冗余字段或缺失关键字段。
- **数据约束**：关键字段是否缺少非空、唯一、外键等数据库层面的约束。
- **数据一致性**：本地状态（如前端 state/内存）与数据库之间的同步机制是否可靠。
- **ID 体系**：是否存在本地生成的 ID 与数据库生成的 ID 格式不一致或冲突的问题。
- **持久化边界**：哪些操作必须落库，哪些操作仅保留在本地，边界是否清晰且合理。

### 2.3 接口风险 (API Risks)
- **鉴权机制**：所有敏感接口是否均有严格的身份验证与权限控制。
- **入参校验**：是否对所有外部输入进行了类型、必填项及边界值的严格校验。
- **异常处理**：是否存在未捕获的异常直接抛出给前端，前端是否能优雅处理错误返回。
- **依赖关系**：接口之间的调用链路是否清晰，是否存在死循环或过度嵌套。

### 2.4 安全风险 (Security Risks)
- **硬编码**：代码中是否明文写死了密钥、密码、IP 地址或 Token。
- **注入防护**：是否存在 SQL 注入、XSS（跨站脚本攻击）等常见 Web 漏洞风险点。
- **输入过滤**：用户提交的任何内容是否都经过了转义和安全过滤。
- **敏感数据**：用户信息、支付数据等是否进行了加密存储或脱敏展示。

### 2.5 业务逻辑风险 (Business Logic Risks)
- **异常分支**：核心业务流程（如交易、状态流转）是否有未覆盖的异常分支（如支付失败、网络中断）。
- **状态回滚**：在多步操作中，若某一步失败，是否具备完整的状态回滚机制。
- **字段传递**：关键业务字段（如订单类型、用户标识）在整个链路中是否能正确、完整地传递。
- **逻辑冲突**：正在修改或重构的模块，是否存在新旧逻辑并存导致的冲突。
- **边界场景**：未登录用户、并发操作等特殊场景下的业务处理是否完整。

### 2.6 可维护性风险 (Maintainability Risks)
- **代码注释**：关键复杂逻辑是否有清晰的注释说明。
- **代码重复**：是否存在大量复制粘贴的重复代码（DRY 原则违背）。
- **魔法值**：是否存在未定义常量的“魔法数字”或“魔法字符串”。
- **可观测性**：系统是否具备基本的日志记录能力，发生故障时能否快速定位问题。

## 3. 审查输出规范

审查完成后，必须输出名为 `系统审查报告_VERIFY_REPORT_[项目代号]_v[版本号].md` 的文件，结构如下：

### 3.1 整体评估结论
用一句话明确表态：当前系统状态是否能够支撑正式上线或进入下一阶段。

### 3.2 优先处理清单
仅列出严重程度为「🔴 致命」的问题，按处理的紧急程度和逻辑顺序排序，作为开发团队的最高优先级任务。

### 3.3 问题汇总表
以表格形式列出所有发现的问题，必须包含以下列：
- **维度**：所属的六大维度之一。
- **问题描述**：清晰描述问题现象及潜在影响。
- **严重程度**：
  - 🔴 **致命**：系统无法正常运行、存在严重安全漏洞或核心业务阻断。
  - 🟡 **需关注**：影响系统稳定性、数据准确性或可维护性，需在近期版本修复。
  - 🟢 **建议优化**：不影响当前核心运行，但影响长期代码质量或扩展性。
- **建议处理方式**：给出具体的修复方向或技术建议。
