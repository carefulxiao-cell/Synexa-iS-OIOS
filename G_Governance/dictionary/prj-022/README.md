## 三、更新与使用

1. 由项目专项提候选，经对应业务Owner核对，然后由iS-Core/PRJ-022对跨域语义审核。
2. 全域正式定义优先在公司认知主源变更并批准，机器索引再从其派生；旧ID不重用，保留历史别名。
3. `terms.json`采用CH26.9.11既有13项规范字段，加来源、审核Owner、别名、扩展备注；`source_confirmed`仅表示原文可见，非本新索引已经获批。
4. 项目词条不直接上收成为集团正式术语；跨项目复用后提出候选，并记录适用边界。
5. 员工、患者、财务原始记录仅限授权业务存储，本公开目录禁止收纳。
