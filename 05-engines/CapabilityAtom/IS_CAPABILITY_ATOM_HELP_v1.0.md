## 一、应用定位

**「能力原子」** 是 Synexa iS 体系的能力管理与调用入口，运行于飞书多维表格平台，负责对体系内所有「能力体」进行结构化登记、状态追踪与跨工作空间引用。

**一句话定义**：将超智能力体系中的每一个可调用能力单元，以标准化「原子」格式登记、管理并提供引用索引。

**与体系的关系**：能力原子是 Synexa iS 四层能力框架（场景智能 → 供应网络智能 → 系统智能 → 协同智能）的操作层入口，将框架中定义的「能力体」概念落地为可管理、可检索、可调用的数字记录。

## 二、知识库摘要（来源：超智基线文件 v2.4）

### 2.1 超智公司定位

超智（Synexa）是一家**协同智能公司（Collaborative Intelligence Company）**，致力于构建复杂场景中的智能集群方案，让人、组织、智能体、设备与供应网络协同持续优化，共同创造更高价值。

超智的核心差异在于：不在数字世界里模拟场景，而是进入真实业务现场，将专业知识、供应链资源、运营服务与数字系统整合为一体，形成可真实交付、可持续迭代的复杂场景解决方案。

### 2.2 四层能力框架

超智的能力由四个层次构成，自下而上相互支撑：

| 层次 | 名称 | 核心职能 |
|------|------|----------|
| **① 场景智能** | Scenario Intelligence | 深入业务现场，理解需求产生与服务交付逻辑，形成场景认知壁垒 |
| **② 供应网络智能** | Supply Network Intelligence | 整合全球优质原材料与服务资源，构建稳定可靠的履约能力 |
| **③ 系统智能** | System Intelligence | 构建专属协同智能系统 Synexa iS，覆盖全业务场景的数智协同 |
| **④ 协同智能** | Collaborative Intelligence | 让人、组织、智能体、设备与资源网络形成持续进化的价值创造系统 |

### 2.3 能力体的四类形态

在超智认知框架中，**能力体（Capability Entity）** 是可被主体调用的能力资源，分为四类：

| 类型 | 说明 | 在体系中的角色 |
|------|------|---------------|
| **数字能力** | AI、Agent、ERP、CRM 等数字化工具与系统 | 协同网络的神经系统 |
| **物理能力** | 机器人、医疗设备、厨房设备、能源设备等实体装置 | 协同网络的执行系统 |
| **网络能力** | 供应网络、服务网络、物流网络等资源流通体系 | 协同网络的循环系统 |
| **知识能力** | SOP、知识库、决策模型等结构化经验积累 | 协同网络的记忆系统 |

**能力原子的登记对象**：以上四类能力体中，所有已接入或规划接入 Synexa iS 体系的具体能力单元，均须在「能力原子」中完成登记。

### 2.4 Synexa iS 系统架构简述

Synexa iS 是超智的专属协同智能系统，由以下核心模块构成：

| 模块代号 | 模块名称 | 职能定位 |

| **iS-Cortex** | 协同皮层 | 中台知识沉淀，三库（PER）持续积累 |
| **iS-Proxima** | 近场智能 | 业务现场端边缘智能，就地感知与执行 |
| **iS-Vena** | 协同数据脉 | 供应协同数据层，FdD 三层架构数据汇聚 |

## 四、调用方式

### 4.1 在飞书多维表格中查询

1. 打开「能力原子」多维表格
2. 使用「类型」「所属模块」「状态」字段进行筛选
3. 点击具体能力原子行，查看完整字段详情
4. 「引用路径」字段提供该能力原子在 GitHub 仓库中的文件路径

### 4.2 跨工作空间引用格式

在 AI 工作空间（Manus、GPT、Kimi 等）中引用能力原子时，使用以下格式：

```
@CapAtom:[能力原子代号]
```

示例：`@CapAtom:IS-Cortex-P-Library` 表示引用 iS-Cortex 场景模式库。

### 4.3 新增能力原子的流程

1. 在飞书「能力原子」表格中新增一行，填写所有必填字段
2. 将相关文件推送至 GitHub 仓库对应目录
3. 更新 `IS_FILE_REGISTRY_v1.0.csv` 完成登记
4. 在 `CONTEXT_OS.md` 中记录新增事项（若为重大能力）
5. 通知 iS-Core 完成状态同步
