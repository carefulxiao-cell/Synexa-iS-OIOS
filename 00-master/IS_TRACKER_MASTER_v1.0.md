> **版本**：v1.2

> **归属**：Layer 3 · 跨组协同层
> **协议标准**：遵循 `TASK_TRACKING_PROTOCOL_v1.0.md` 的 11 字段规范

## 字段说明（对齐 TASK_TRACKING_PROTOCOL）

| 字段 | 说明 |
|---|---|
| **任务ID** | 格式：`[工作空间代号]-[序号]`，如 `N2U-001` |
| **任务名称** | 简洁描述任务目标 |
| **优先级** | P0 紧急 / P1 高 / P2 中 / P3 低 |
| **状态** | ⬜ 待启动 / 🔵 进行中 / 🟡 待确认 / 🟣 审查中 / ✅ 已完成 / 🔴 已阻塞 |
| **负责方** | 执行该任务的工作空间代号或角色 |
| **创建日期** | YYYY-MM-DD |
| **更新日期** | 最后一次状态变更的日期 |
| **依赖项** | 前置任务 ID 或条件 |
| **交付物** | 任务完成后的可验证产出 |
| **阻塞原因** | 当状态为「已阻塞」时必填 |
| **备注** | 补充说明 |
