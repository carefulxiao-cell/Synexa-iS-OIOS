# 版本变更记录模板 (IS_CHANGELOG_TEMPLATE)

**版本**: v1.0
**适用范围**: Synexa iS 体系下所有项目通用
**定位**: 规范每次系统迭代或发布的记录格式，确保变更历史可追溯、影响范围清晰，便于跨角色沟通与审查。

---

## 模板使用说明

1. 每次系统进行实质性变更（无论是否正式发布上线），均需按此模板新增一条记录。
2. 记录应按时间倒序排列（最新的变更在最上方）。
3. 占位符 `[ ]` 中的内容需根据实际情况替换。
