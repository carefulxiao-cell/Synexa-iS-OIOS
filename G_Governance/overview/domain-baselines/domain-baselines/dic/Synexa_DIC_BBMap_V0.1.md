# 超智科技·数智协同基线蓝图地图｜DIC·BBMap V0.1

> **定位说明**：本文件是 DIC 领域认知蓝图（BBMap），定义术语、关系、机制与生产链条。
> HTML 生产规范（COVER 块、stat 提取、脚本调用）继承全局 BBM（Baseline_Builder_Master.md），本文件不重复定义。

## 1. 职责与定位
- **文件类型**：Domain / Operational Baseline｜专题运行基线
- **中文正式名**：超智科技·数智协同基线
- **英文正式名**：Synexa Digital-Intelligence Collaboration Baseline
- **对外轻主名称**：DICB
- **上位文件**：超智科技认知基线 V3.10 (Master SSOT)
- **核心职责**：定义人、AI、Agent、工具、代码、系统与真实项目如何协同推进任务。

## 2. 核心内容
- **角色关系**：人智判断、AI/LLM、Agent、Python/Code、业务系统、经验资产的边界。
- **任务归位**：任务如何被拆解、分配给不同的执行体。
- **标准路径**：人智定向 → 数智执行 → 人智裁决的协同主流程。
- **最小闭环**：点餐体验 → 生产保障 → 服务运维 → 采购支持 → 人力管理 → 财务管控 → 经验沉淀。
- **能力资产**：10 项首批 Skill 清单（含日常运维与 MetaSkill 储备）。

## 3. 不包含的内容
- **不包含具体业务逻辑**：如具体的营养规则、菜品配方（属于 Nex2U / NexChef 引擎）。
- **不包含系统开发代码**：如打单系统的具体实现（属于执行包）。
- **不包含全局治理规则**：如文件命名规范、版本审计机制（属于 Master SSOT）。

## 4. 层级归位
- **在 Synexa iS 中的位置**：属于“数智协同运行层”的专题基线。
- **与 Master SSOT 的关系**：继承 V3.10 的公司定位、能力体系和系统架构，不改变项目组合关系。

## 5. 生产链条与关系
- **DIC·BBMap**：定义蓝图、职责、边界与核心要素。
- **DIC·BBLx**：定义章节展开逻辑、渲染规范与排版要求。
- **DICB (md)**：Markdown 主源，承载完整规范性内容。
- **DICB (html)**：渲染输出的阅读版。
- **生产链条**：`DIC·BBMap → DIC·BBLx → DICB (md) → DICB (html)`
