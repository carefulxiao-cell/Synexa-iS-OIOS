## 一、 前端（Nufō³）分层逻辑与用户价值深化

前端交互层（Nufō³）的核心目标是在不增加生产端个性化定制压力的前提下，为不同性质、不同对象的用户提供精准的健康稳态餐食服务，并建立长期的健康数据反馈回路。

### 1. 履约性质与服务对象分层

系统提供堂食与送餐两种核心履约模式，以覆盖医院或饭堂的全场景需求。堂食模式分为临时点餐与提前预约，前者基于当前库存和剩余产能进行快速筛选，后者则锁定产能并支持更丰富的结构点选择。送餐模式同样支持临时点餐与预约送餐，满足病区或办公区的即时补给以及规律性的三餐配送需求。

在服务对象方面，系统通过泛化后的“身份码”识别用户身份，并赋予不同的权限、补贴规则和推荐权重。

| 身份类型 | 核心需求特征 | 侧重场景 | 补贴与权限 |
| :--- | :--- | :--- | :--- |
| **医护/工作人员** | 高强度脑力/体力消耗 | 工作补能、抗疲劳 | 支持内部补贴核销 |
| **病患** | 强约束条件，需遵医嘱 | 特护膳食、慢病管理 | 严格遵循禁忌标签 |
| **陪护/家属** | 中等强度消耗 | 日常均衡、免疫支持 | 标准化推荐 |
| **随机/来访者** | 无历史数据 | 大众健康 | 标准化推荐 |

### 2. 场景与结构推荐逻辑

这是解决个性化需求与标准化生产矛盾的关键机制。系统采用三级分类漏斗：首先选择餐次（早餐、正餐、加餐），其次选择功能类别（即 28 个主题场景，如高蛋白早餐、术后恢复），最后进行目标对象需求匹配。

用户选择二级功能类别后，系统并非为其单独定制菜品，而是通过**结构约束引擎**，在现有的标准化菜品库中，筛选出符合该功能类别（如高蛋白、低钠）的菜品组合。用户在系统划定的安全结构内自由替换菜品。这种结构驱动而非单品定制的模式，既满足了个性化营养需求，又保证了后厨的标准化批量生产。

### 3. 数据反馈与增值服务拓展

为了增强用户黏性，系统在购物车环节直观展示本餐营养摄入与该场景目标区间的对比，辅助用户决策。在个人中心，系统提供周或月维度的营养摄入趋势图。基于用户的历史点餐数据和设定的健康目标，系统能够推演出最适合用户当前状态的建议。

在核心餐食之外，系统通过数据推演提供高附加值的增补项。例如，针对下午茶或夜宵场景推荐功能性加餐；基于用户的慢病标签推荐健康周边产品；并为有深度需求的用户提供付费的线上营养师咨询入口。

## 二、 后端（NuBō）数据引擎生态与价值挖掘

后端执行层（NuBō）不仅是订单处理中心，更是整个 Nex₂U 体系的数据中枢和供应链驱动引擎。

### 1. 传统团餐模式的数字化重构

系统致力于将宜源华等传统团餐公司的经验转化为可计算的数字资产。传统菜单提交后，系统自动进行营养结构点落点分析，识别菜单的营养短板或结构失衡。系统输出优化建议后，经营养师审核批复，形成全员对齐的标准化数字菜单。确认后的数字菜单直接通过 Nexsply 接口，自动拆解为精确到克的原材料采购计划，并进行全程库存与损耗跟踪。

### 2. 领先的财务与数据结构

系统超越传统的进销存和营收利润模型，建立多维度的健康餐饮财务模型。

| 财务分析维度 | 核心指标与价值 |
| :--- | :--- |
| **基础财务** | 日/周/月营收、客单价、退款率、各支付渠道对账。 |
| **结构性成本分析** | 精确到营养结构点的成本核算，例如获取单位优质蛋白的平均成本，以及不同食材的成本转化率对比。 |
| **场景效益分析** | 28 个主题场景的独立利润率核算，识别高毛利场景与引流场景。 |
| **损耗追踪** | 基于标准 BOM 与实际消耗的差异分析，精准定位后厨损耗环节。 |

### 3. 数据蒸馏与高价值提炼规划

为了让流动的数据产生复利价值，系统统一收集前端交互数据、交易数据、后端生产数据和供应链数据，并清洗掉无效噪音。高价值的蒸馏方向包括：构建用户偏好图谱以指导新品研发；建立价格敏感度模型以指导定价策略；以及基于历史周期和季节因素的供应链预测模型，以降低库存积压。系统将建立自动化的数据清洗流水线，定期生成运营与营养洞察简报。

### 4. 全面扫描与分段落地路径

兼顾当下可行性与长期价值，系统规划了严谨的四阶段落地节奏。

| 阶段 | 周期 | 核心目标 | 关键任务 |
| :--- | :--- | :--- | :--- |
| **Phase 1：基建与跑通** | 第 1-4 周 | 跑通场景选择到后厨接单的最小闭环 | 建立营养结构点数据库，重构前端基础交互，替换旧电商后台逻辑。 |
| **Phase 2：数据沉淀与反馈** | 第 5-8 周 | 建立用户健康档案，上线营养对比和趋势图 | 完善用户身份体系，打通前端行为与后端订单数据的关联。 |
| **Phase 3：供应链驱动与财务深化** | 第 9-12 周 | 实现菜单自动拆解采购计划，上线成本分析看板 | 对接 Nexsply 供应链逻辑，深化财务数据模型。 |
| **Phase 4：智能推演与增值拓展** | 第 13 周以后 | 上线智能推荐，引入增值商品与服务 | 引入 AI 推荐算法，丰富商品库结构。 |
