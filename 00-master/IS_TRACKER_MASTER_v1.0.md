# 全局推进台账 · Master Tracker
> **版本**：v1.0
> **状态**：🟢 活跃
> **归属**：Layer 3 跨组协同层
> **定位**：iS 体系全局任务推进的唯一真相源，按优先级排序，指导下一步行动。

---

## 字段结构说明

| 字段 | 说明 |
|---|---|
| **优先级** | P0(阻塞修复) / P1(核心推进) / P2(基础设施) / P3(孵化排队) |
| **项目/引擎** | 任务归属的模块或引擎 |
| **当前状态** | 任务当前所处的 Step 或阶段 |
| **下一步行动** | 明确的、可执行的下一步动作 |
| **阻塞/依赖** | 推进该任务需要解决的前置条件 |
| **执行工作空间** | 该任务应该在哪个对话组中执行 |

## 跟踪与更新机制

1. **日常更新**：任何工作空间完成里程碑节点后，必须通过 `更新任务台账` 触发词同步更新本文件。
2. **全局审查**：iS-Core 定期通过 `全局任务审查` 触发词，扫描本文件，重新评估优先级。
