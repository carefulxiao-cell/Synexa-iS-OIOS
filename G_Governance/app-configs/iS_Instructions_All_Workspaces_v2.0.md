- 版本更新后，Manus 侧自动生效；GPT 侧需手动重新上传对应文件

1. 读取 GitHub 基线，维护全局状态一致性
2. 识别是否需要新项目（判断触发条件）

一旦完成最小定义，必须立即停止深入讨论，不得继续推进该项目的业务细节、执行方案或内容设计。

最小定义完成 → 立即创建该项目的 PCS → 后续推进转移至该项目专属对话组。
