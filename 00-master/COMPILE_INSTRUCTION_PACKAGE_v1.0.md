## 三、文件生产规范

1. **每个文件生产前**：先读取 `CONTEXT_OS.md` 确认最新全局状态，避免与已有裁决冲突
2. **文件命名**：遵循 `SOP_002` 命名规范，版本号格式 `_v[主版本].[次版本]`
3. **生产完成后**：推送至 GitHub，更新 `EXECUTION_TRACKER.md` 对应任务状态为「已入库」
4. **重大内容变更**：触发 CONTEXT_OS.md 待同步事项更新，并提示 GPT 同步
