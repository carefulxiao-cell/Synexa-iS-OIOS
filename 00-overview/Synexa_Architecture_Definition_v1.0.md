# Synexa 体系架构定义 (Synexa Architecture Definition)

> **版本**：v1.0
> **生效日期**：2026-04-09
> **核心定位**：一个可复制的商业操作系统雏形
> **核心主张**：让增长来自结构，而不再依赖单点能力。让协同成为生产力，而不是成本。

---

## 一、四层架构体系 (Four-Layer Architecture)

整个 Synexa 体系由上至下分为四个层级，各司其职，互不越界。

### ① Brand Layer｜品牌层
**Synexa｜超智**
- **定位**：顶层商业标识 / 系统叙事入口
- **标准定义**：Synexa，是一个以协同为核心、驱动系统性效能的基础平台，围绕健康生活方式重构资源与增长结构。

### ② System Layer｜系统层
**Synexa iS｜智能系统基座（Intelligent System）**
- **职责**：协同调度、决策支撑、能力组织、数据与规则运行
- **一句话定义**：Synexa iS，是驱动体系协同、承载决策与能力运行的智能系统基座，一个“可扩展的商业操作系统雏形”。
- ⚠️ **防塌规则**：Synexa iS 不做业务，不直接产生收入，只提供能力与调度。

### ③ Module Layer｜模块层
**iS Modules｜智核模块体系**
- **标准定义**：iS Modules，是构成 Synexa iS 的功能单元，负责不同维度的能力实现（组织操作系统级别）。
- **当前模块**：
  - `iS-Core`：治理与裁决（最终决策）
  - `iS-Hub`：资源与情报（连接外部）
  - `iS-SCO`：战略推演（未来判断）
  - `iS-Matrix`：结构化生产（标准/方法/模板）
  - `iS-PCS`：项目执行系统（推进器）
  - `iS-Lab`：创新验证（试错场）

### ④ Engine Layer｜业务引擎层
**Nex Engines｜业务引擎体系**
- **标准定义**：Nex 系列，是在不同场景中运行的业务引擎，直接面向市场并产生价值与收入。
- **当前结构**：
  - `Nex₂U`｜智食引擎
  - `NexSply`｜供应链引擎
  - `NexChef`｜餐食方案 / 具身智能
  - `NexEP`｜扩展业务引擎
- ⚠️ **关键规则**：所有收入、用户、市场，全部发生在 Nex 层，而不是 iS 层。

## 二、体系灵魂与飞轮效应 (System Soul & Flywheel)

### 核心关系链路
1. **Synexa** 定义规则
2. **iS** 进行调度与决策
3. **Modules** 提供能力与工具
4. **Nex** 执行并产生收入与数据
5. 数据回流 **iS** 优化结构
6. 结构反哺 **Nex** 提升效率

### 增长飞轮
**Synexa → iS → Modules → Nex → 反馈**
Nex 引擎负责收入与市场，iS 系统负责效率与复用。两者通过数据与结构联动，形成持续增长的经营闭环。

---

## 三、对外沟通口径 (External Communication)

### 极简版本
> Synexa 是我们的系统底座，iS 是运行系统，Nex 是产生价值。
> 我们通过 Synexa iS 构建协同能力，再通过 Nex 系列在不同场景中实现商业化。

### 核心三件事（对外只讲这三点）
1. 我们做健康生活方式系统
2. 我们有自己的系统（Synexa iS）
3. 我们有具体业务（Nex₂U 等）

### 商业化愿景：Synexa iS™
iS 不只是内部系统，而是可以对外输出的“能力体系”（方法论品牌）。
未来演进路径：卖系统 → 做咨询 → 做平台。

## 四、Nex 引擎标准化描述框架 (Nex Engine Framework)

每一个 Nex 业务引擎，都必须用以下“收入结构 + 数据流 + 组织角色映射”的框架进行描述：

1. **收入结构（Revenue）**
   - 收谁的钱？
   - 通过什么方式收费？（单次 / 订阅 / 分润 / 服务费）
2. **核心产品（Product）**
   - 提供什么具体价值？
   - 用户为什么付钱？
3. **数据输入（Input）**
   - 用户数据 / 供应链数据 / 运营数据
4. **数据输出（Output）**
   - iS 用来优化什么？
   - 形成哪些模型 / SOP / 决策规则？
5. **iS 依赖（System Dependency）**
   - 用到哪些模块（如 iS-Hub 找资源，iS-Matrix 定标准，iS-SCO 做策略）
