## 0. 使用规则

1. 新 Codex 对话框启动时，先读取本文件，再读取对应主题的恢复提示词。
2. 本文件只记录已确认或可追溯的信息。无法从源文件确认的内容必须标注“待确认”。
3. 任何主题任务产生关键结论后，必须回写本总账的主题状态、资产清单、已确认原则、待确认事项或下一步。
4. 原始数据、原始品名、原始场景、原始字段、原始价格描述不得覆盖；清洗、判断、映射字段只能作为派生字段追加。
5. Markdown 总账是结构主源；HTML 导航页是人看的总览表达层。事实更新优先回到本总账。
6. 各级 HTML 工作台 / 导航页应启用“重点文件清单”结构，直接说明有什么、对应功能是什么、当前缺什么；日常推进记录按从近到远倒序排列。
7. 工作台正式应用命名集中表达：L1=总控台，L2=任务跟踪台 / 餐食运营台 / 人力管理台 / 财务分析台 / 系统工具台；同一工作台的 Markdown 与 HTML 入口放在同一表格单元格内，不拆成多行。
8. HTML 视觉统一采用超智 CI 规范：白底、细灰线、深灰字、低面积点缀色；字体优先使用本地 Noto Sans CJK，英文/数字可用 Space Grotesk，代码/路径可用 JetBrains Mono。
9. 各工作台应有“核心工作”版块，按“核心工作 → 核心内容”两层表达，先呈现专项工作的核心逻辑、任务节点和路径规划，再承接表格清洗与执行任务。
10. 全局 HTML 工作台优先采用同构模块顺序：顶部身份区、四大入口导航、指标卡 / 当前状态、主链路、主链路明细、关键字典、核心场景 / 任务、专项看板、重点文件清单、核心工作列表、日常推进记录、恢复提示词。
11. 全局 HTML 顶部导航统一只保留四大入口按钮：L1·总控台、L2·餐食运营台、L2·人力管理台、L2·任务跟踪台；页面内部锚点、Markdown、项目总账、基线文件等放入重点文件清单或正文，不放在顶部导航区。

## 6. 当前已确认原则

- 产品 SKU 是可独立售卖、结算、沟通、上菜单、上系统的产品单位。
- 结构点 SKU 是厨房最小生产 / 出品任务单位；A/B/C/D 套餐不是结构点 SKU。
- 食材 SKU 是采购、库存、供应商和成本管理对象，不能与结构点 SKU 混用。
- BOM 是结构点 SKU 与食材 SKU、用量、单位、出成率、成本之间的桥。
- SOP = BOM + 备料过程 + 烹饪过程 + 出品标准 + 装盒/打包标准 + 器皿 + 温控 + 标签 + 生产节点 + 风险点 + 质量验收。
- 场景线回答“谁吃、按什么产品和服务规则履约”；配送路线回答“送到哪里、按什么路径履约”；二者通过履约单元绑定。
- 原始数据不得覆盖，清洗字段、判断字段、映射字段必须追加。
- 菜单不是菜名集合，而是结构点、产品 SKU、食材供应、厨房能力、配送路线、价格策略和用户体验共同作用的结果。
- 金额展示必须带 `￥`；数值类带千位符。
- `99` 是排序码，不是价格；日月潭茶叶蛋价格锚定为 `￥3`。
- 旧状态“暂缓”不用；新版状态为：上线、待上·1周内、研发·3周内、待研发·3周后。
- 月子餐需要区分 VIP 和普通病房；月子一日餐不是一个全日套餐，每个餐点都是独立结算项。
- 手术室、介入手术室、行政专家餐、志愿者餐、爱心餐、感控 / 特殊限制膳食应作为独立场景线处理。
- 指挥与策略层、中台运营与支持层、前线执行与履约层是当前人力结构的三层框架。
- L2 餐食运营台的核心工作骨架为双向推演链：现实反推线从终端菜单拆到 SKU、结构点、食材、成本、营收和复盘；设计正推线从人群需求、营养结构点、产品策略推到菜单、采购、成本和营收。
- “人力协同专项导航”是旧文件名 / 旧入口称谓；当前统一定位为“人力管理台”。二者当前指向同一 HTML 入口，不是两个独立工作台。
- 正式应用命名统一使用“台”：总控台、任务跟踪台、餐食运营台、人力管理台、财务分析台、系统工具台。旧文件名暂不强改，避免破坏已有链接。
- 菜单审核线已接入 5/4-6/14 历史周菜单 Excel 和 0622-0628 三张菜单图片；当前状态是“已接入，待结构化抽取 / OCR / 人工校对”，不是“待收集”。
- L2 餐食运营台主链路统一为短词节点：场景线 → 终端菜单 → 产品 SKU → 结构点池 → 结构点 SKU → 食材 SKU → BOM → SOP → 菜单模型 → 采购模型 → 生产配送 → 营收营利 → 复盘。
- 全系统页面应逐步同构为：顶部身份区、四大入口导航、指标卡 / 当前状态、主链路、主链路明细、关键字典、核心场景 / 任务、专项看板、重点文件清单、核心工作列表、日常推进记录、恢复提示词。
- 2026年05月番医供应商采购明细表已接入 T3，已确认其包含供应商采购汇总、采购明细、产品规格换算、库存盘点、产品明细和产品明细占比 6 个 sheet；规格换算字段已存在，但是否为最新正式口径仍待人工确认。
