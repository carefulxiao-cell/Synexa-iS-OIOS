## Step 0A · 最小定义

### 1. 项目名称

**超智建设 · iS-Synexa**

### 2. 一句话定义

> Synexa（超智）品牌体系的建设与对外表达，涵盖品牌官网、介绍材料、视觉规范与对外叙事框架，是整个生态对世界说话的方式。

### 3. 层级归位

**G·集团级**

理由：本项目的对象是 Synexa 品牌本身，而非某条业务线或功能模块。它的产出（网站、介绍、品牌规范）是整个生态的对外界面，影响所有下属业务线的认知基础。

### 4. 优先级判断

**P2·次优先**（当前最高优先级为 iS-Nex2U Step 3 推进）

判断依据：
- Synexa 品牌建设属于"基础设施"类工作，不阻塞业务线运转
- 但随着 Nex₂U 等项目推进，对外表达需求会逐步浮现
- 建议在 Nex₂U 完成 Step 3 后，同步启动 iS-Synexa 的 Step 0B

### 5. 核心任务范围（初步边界）

本项目承接以下类型的工作：

| 任务类型 | 说明 | 归属工作空间 |
| :--- | :--- | :--- |
| 品牌战略与叙事框架 | Synexa 是什么、为什么存在、如何对外表达 | iS-SCO 推演 → iS-Synexa 执行 |
| 品牌官网 | 官方网站设计与开发 | iS-Synexa 执行 |
| 介绍材料 | 品牌介绍、体系介绍、合作方说明文档 | iS-Synexa 执行 |
| 视觉规范 | Logo、色彩、字体、排版等品牌视觉系统 | iS-Synexa 执行 |
| 可复用品牌模板 | 对外文档模板、PPT 模板等 | iS-Matrix 固化为资产 |

### 6. 明确不在本项目范围内的事项

- Nex₂U、Nexsply、Bella Giornata 等子品牌/业务线的品牌建设（各自在对应 PCS 内处理）
- Synexa iS 体系内部的架构文档与治理文件（归属 iS-Core 治理）
- SOP 与操作规程的生产（归属 iS-Matrix）
