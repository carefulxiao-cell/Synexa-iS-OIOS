## 一、分层架构说明

本注册表依据超智基线 CH11 定义的 Synexa iS 五层架构进行工作空间归位。分层原则为**功能层级归位**，而非重要性排序。

| 层级代号 | 对应 CH11 架构层 | 定位 |
|---|---|---|
| **G 层** | Governance Layer（治理规则层） | 全局裁决、战略推演、知识沉淀、情报、实验、输出标准 |
| **A 层** | Agent-Swarm Layer（智能集群层） | 具体任务的 Task Room，各项目专属 PCS 对话组 |
| **E 层** | Nex·EC（业务引擎层） | 各核心业务引擎的治理入口与协同空间 |
| **N 层** | Nex·PVC（协同神经体层） | 近场感知、数据脉络、经验沉淀 |
| **P 层** | 个人效能层 | 个人探索与效能提升，不参与体系协同 |

## 五、N 层 · 协同神经体层（Nex·PVC）

N 层是 Nex·PVC 的工作空间，负责近场感知、数据脉络串联和经验沉淀。N 层不直接参与业务执行，而是为 E 层提供神经支撑。

**认知负荷说明：** N 层的存在，确保感知、数据、经验三类能力有独立的治理空间，不与业务执行混淆。

| 编号 | 工作空间 | 对应 Nex·PVC 组件 | 职责 | 消除的认知负荷 |
|---|---|---|---|---|
| **N1** | **iS-Proxima** | Proxima（近场感知） | 就地感知 / 就地判断 / 就地执行，联动现场设备与岗位终端 | 消除现场信号无法及时传递的延迟 |
| **N2** | **iS-Vena** | Vena（协同数据脉） | 数据接入 / 清洗 / 建模 / AI-ready 数据，联动 NexLens 与 iS-Cortex | 消除数据孤岛与字段不一致 |
| **N3** | **iS-Cortex** | Cortex（协同皮层） | Pattern / Exception / Rule / Field 经验沉淀，联动所有项目复盘 | 消除经验不沉淀、规则不成文的系统性遗忘 |
