## 二、飞书多维表格导入步骤

1. 打开飞书，进入目标多维表格
2. 点击左下角「+ 添加数据表」→「从 CSV 导入」
3. 上传对应 CSV 文件
4. 确认字段映射（飞书会自动识别列名）
5. 完成导入后，手动将以下字段类型调整为更合适的格式：

### 任务清单推荐字段类型调整

| 字段名 | 推荐类型 | 说明 |
| :--- | :--- | :--- |
| 状态 | 单选 | 选项：待启动 / 进行中 / 已完成 / 已阻塞 |
| 优先级 | 单选 | 选项：P0（必须）/ P1（重要）/ P2（可延后） |
| 工作线 | 单选 | 选项：准备 / 基建 / 线A·引擎 / 线B·前端 / 线C·后台 / 联调 / 部署 / 验收 |
| 阶段 | 单选 | 选项：第一周 / 第二周 |
| 负责工具/角色 | 多选 | 选项：Manus / GPT / Code / 技术负责人 / 运营负责人 |
| 计划开始日 / 计划结束日 | 日期 | 根据实际项目启动日期填入具体日期 |
| 依赖前置 | 文本 | 可后续改为关联字段，关联同表的任务编号 |
| 交付物 | 文本 | — |

## 三、作为可复用模板的使用方法

本套表格设计为**通用型产品开发项目模板**，适用于同类型的前后端系统开发项目。复用时只需：

1. **复制多维表格**（飞书支持复制整个数据表）
2. **修改项目名称和任务内容**，保留字段结构
3. **重置所有状态为"待启动"**
4. **根据新项目调整工作线和阶段划分**

### 模板适用场景

- 前后端分离的 Web 应用开发
- 含微信生态（服务号 + 支付）的 H5 项目
- 需要云端部署的 SaaS 类产品
- AI 引擎 + 管理后台 + 用户前端的三层架构项目

## 四、与 GitHub 的协同关系

| 工具 | 职责 | 更新方式 |
| :--- | :--- | :--- |
| **飞书多维表格** | 日常任务追踪、进度可视化、团队协作 | 人工实时更新 |
| **GitHub（Nex2U_Sprint_Plan_2W.md）** | 文档级存档，AI 可读取 | 阶段性更新（每周或里程碑时） |
| **Manus** | 读取 GitHub 文档，执行开发任务 | 自动读取最新版本 |

> 建议：飞书表格作为日常工作面板，GitHub 文档作为阶段性快照。每完成一个里程碑，将飞书表格的最新状态同步回写至 GitHub。
